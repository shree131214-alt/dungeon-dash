# Dungeon Dash

A small, beginner-friendly Python terminal game. Pick a sword, shield, or spell and try to win two rounds before the dungeon creature does.

## Play

Requires Python 3.8 or later. No extra packages are needed.

```bash
python main.py
```

## Run the tests

```bash
python -m unittest
```

## What you'll practice

- Functions, loops, and conditionals
- Lists and dictionaries
- Keyboard input and random choices
- Automated tests with Python's built-in `unittest`
